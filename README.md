### 🚀 About Me

I am a Software Engineer with an interest in medical devices and embedded systems. As a lifelong Type 1 diabetic i've been around many different type of medical devices from insulin pumps, glucose sensors, blood pressure monitors, hearing aids, and from being around them for so long i've wanted to help improve these devices that make my life manageable.

🔭 &nbsp;I'm currently working on **An embedded systemns lab**  
🌱 &nbsp;I'm currently learning **C/Assembly**  
👯 &nbsp;I'm looking to collaborate on **open-source insulin pumps**  
💬 &nbsp;Ask me about **Proxmox,Linux,Embedded Systems**  
😄 &nbsp;Pronouns: **he/him**  
⚡ &nbsp;Fun fact: **I host and manage a netflix style media server/homelab for me and a couple of my friends.**
